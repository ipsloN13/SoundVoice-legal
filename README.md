# SoundVoice-legal

Y - Sound Voice — PUBLICAÇÃO NO GITHUB PAGES


1. Abre index.html, terms.html e privacy.html num editor de texto e substitui todos os campos [ENTRE PARÊNTESES RETOS].

2. Confirma especialmente os factos relativos a gravação de áudio, armazenamento, logs, alojamento, fundamento jurídico e conservação de dados. Consulta apoio jurídico se necessário.

3. Cria um repositório público no GitHub com o nome y-sound-voice-legal.

4. Envia para a raiz do repositório os quatro ficheiros: index.html, terms.html, privacy.html e style.css.

5. No repositório, abre Settings > Pages. Em Build and deployment, escolhe Deploy from a branch, branch main e pasta /(root). Guarda.

6. Aguarda a publicação e abre:
   
   https://TEU-UTILIZADOR.github.io/y-sound-voice-legal/

   https://TEU-UTILIZADOR.github.io/y-sound-voice-legal/terms.html

   https://TEU-UTILIZADOR.github.io/y-sound-voice-legal/privacy.html

8. Confirma que as páginas estão acessíveis publicamente e copia os dois últimos URLs para o Discord Developer Portal.


Nota: o GitHub Pages exige um repositório público nos planos gratuitos usuais. Os URLs acima são exemplos e só funcionarão após publicação.
